# Online Courses Catalog

Тестовое задание: карточный каталог онлайн-курсов с живым поиском и фильтрацией по категориям.

Макет: [Figma](https://www.figma.com/design/iuXLXifXgv4ZCzad0KeYKr/Test-Task?node-id=0-1)

Демо: [GitHub Pages](https://ellanskii.github.io/online-courses-catalog/)

## Стек

- HTML — семантическая разметка по БЭМ
- SCSS — стили по БЭМ, компиляция через Vite + sass
- JavaScript (vanilla) — ES-модули, без фреймворков и библиотек
- Vite — сборщик и dev-сервер с HMR
- pnpm — пакетный менеджер

## Запуск

```bash
pnpm install      # установить зависимости
pnpm dev          # dev-сервер с hot-reload → localhost:5173
pnpm build        # продакшн-сборка → dist/
pnpm preview      # превью продакшн-сборки
```

## Реализовано

- Pixel-perfect вёрстка по макету (диапазон 320px → 1920px)
- Резиновый адаптив без жёстких брейкпоинтов: `clamp()`, относительные единицы, `grid-template-columns: repeat(auto-fill, minmax(280px, 1fr))`
- Живой поиск по названию карточек (событие `input`, регистронезависимо)
- Фильтрация по категориям со счётчиками и активным состоянием (`filters__item--active`)
- Поиск и фильтр комбинируются и работают над одним стейтом
- Пагинация по 9 карточек с кнопкой «Load more»

## Осознанные отклонения от макета

- Опечатки и неточности в названиях/тексте курсов из макета частично исправлены
- Заголовок блока выровнен по центру — на макете не по центру, но так выглядит аккуратнее

## Что можно улучшить

- Анимация появления карточек при фильтрации/поиске
- Skeleton-лоадер при первом рендере
- Debounce на поиск
- Сохранение состояния фильтра и поискового запроса в URL (`?category=design&q=...`)
- Accessibility: `aria-live` для результатов поиска
- Для обложек карточек по-хорошему стоит задать `srcset` / использовать `<picture>` с разными размерами и форматами (webp/avif) для оптимизации загрузки на разных экранах
